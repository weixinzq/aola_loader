# 阶段 3：PetMovie 叶资源规则迁移

本批次把背包动态模型 `peticon/movie/type0` 的 URL 识别、规则快照、隐藏模板、类名适配、已知分片类计数和高清比例补偿迁入 `PetMovieResourceRule`。规则只生成框架无关的远程计划，完整响应由共享执行器在 16 MiB 上限内抓取并转换；探测、抓取或转换失败时继续请求未修改的官方原 URL，不向 Flash 提交部分候选字节。

旧 `AolaThemeRequestHandler` 中的 PetMovie 分支和对应辅助方法已移除。验证器覆盖关闭放行、精确 host/path、目录与文件 ID 一致性、5486/5530 的 45 个类标记契约、错误计数拒绝和隐藏模型 6025 模板计划。

既有逆向证据表明 5486/5530 四个分片的等长类标记数分别为 45/39/36/36，且候选经过 FFDec 复读。此次只完成构建、纯逻辑和静态证据验证；真实 Flash 默认/替换/关闭重开/新进程路径仍待执行。
