## 未实施的主题即时刷新方案

同进程主题受到 ControlBarSkinHandler 与 ApplicationDomain 缓存约束。当前保存主题不会自动刷新，也不发送服务器换肤命令。历史虚拟皮肤 ID 和新 ApplicationDomain 方案都涉及 controlv2 核心补丁，尚未实施；如再次推进，需先确定具体范围，再保留原件、静态核对并做双路径实机验证。不要从旧任务表推定已经选定方案。
